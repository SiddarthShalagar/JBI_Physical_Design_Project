# JBI Physical Design Project

## Overview

This project demonstrates complete ASIC Physical Design flow implementation for the JBI block using industry standard EDA tools.

## Tools Used

- Cadence Innovus
- PrimeTime
- TCL Scripting
- Linux

## Flow Implemented

- Floorplanning
- Power Planning
- Placement
- CTS
- Routing
- Timing Closure

## Key Highlights

- Congestion optimization
- Timing optimization
- Clock tree implementation
- TCL automation
